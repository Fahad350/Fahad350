# 🚀 Featured Projects

## 🛒 Shopify Inventory Sync

**Commerce / Inventory Integration · Ruby on Rails**

A Rails application that keeps product stock aligned between a Shopify store and an internal inventory record.

**Tech:** Ruby on Rails · PostgreSQL · Sidekiq · Redis · Shopify Admin API

**Key Areas:**

* Product and variant mapping
* Inventory reads and writes through the Shopify Admin API
* Webhook handling for stock changes
* Sync state in PostgreSQL
* Background imports and retries with Sidekiq
* Redis-backed job processing

---

**Tech:** Ruby on Rails · React · PostgreSQL · AWS S3 · Sidekiq · Redis · REST APIs

**Key Areas:**

* Property & project management
* Document and folder management

* AWS S3 file storage
